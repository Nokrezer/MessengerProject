# Messenger Project

End-to-end асинхронный мессенджер с современным шифрованием(для учебных целей!).

## Стек
- **Backend:** FastAPI, WebSockets, JWT
- **Криптография:** Diffie-Hellman + ChaCha20
- **База данных:** MariadDB

## Особенности
- **End-to-End Encryption** — шифрование сообщений через асинхронный протокол
- Асинхронная обработка WebSocket-соединений
- Поддержка до 50 одновременных пользователей
- JWT-аутентификация
- Хранение сообщений в PostgreSQL

## Статус
Функциональный MVP с базовым E2E шифрованием.

## Установка и запуск

### Требования
- Python 3.10+
- PostgreSQL

## Криптографические механизмы
- **Diffie-Hellman:** согласование ключей
- **ChaCha20:** симметричное шифрование
- Ключи хранятся на сервере и клиенте отдельно (E2E модель)
